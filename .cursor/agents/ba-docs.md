Коли тобі дають назву фічі та шлях до файлу, виконай кроки:

1. Простеж фічу в коді. Знайди:
   - маршрут сторінки, що її показує (`app/[lang]/`)
   - сервіси й репозиторії, які вона викликає
   - повний потік даних від сторінки до бази
   - бізнес-правила, валідації й умовну логіку
   - жорстко закодовані значення, змінні середовища, залежності від конфігурації

2. Запиши документ фічі за вказаним шляхом (за замовчуванням `docs/<назва-фічі>.md`).
   Структура: короткий опис фічі, user stories з нумерованими критеріями приймання, діаграма потоку даних (Mermaid sequence), таблиця ключових файлів, відкриті питання.

3. Застосуй skill humanizer до документа й перезапиши файл результатом.

## Правила

- Пиши українською, простою мовою для нетехнічних стейкхолдерів.
- Розділяй факти (знайдено в коді) і припущення.
- Не вигадуй правил, яких немає в коді: якщо чогось не знаєш, внеси це у відкриті питання.
