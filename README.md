# SDDwithAI26-template

Шаблонний репозиторій для практичного курсу **«Spec Driven Development with AI»** (для бізнес-аналітиків і PM).

Це спрощена навчальна копія сайту Фонду Лятошинського (оригінальний проєкт: https://github.com/Liatoshynsky-Foundation/lf-client). Для навчання не потрібні справжня база даних і зовнішні сервіси: при запуску застосунок сам створює базу MongoDB у пам'яті й наповнює її демо-даними. **База скидається при кожному запуску.**

## Як створити власну копію (для учасників)

1. Відкрийте цей репозиторій на GitHub і натисніть **Use this template → Create a new repository**.
2. Назвіть копію `SDDwithAI26-<ваше-імʼя>`.
3. Видимість: **Public** (репозиторій має бути публічним на час навчання, щоб ментор міг перевірити ваші Pull Request).
4. Натисніть **Create repository**.

Далі працюйте у **своїй копії**, а не в шаблоні. Покрокові інструкції по днях ви знайдете на навчальній платформі.

> Не кладіть у репозиторій паролі, токени та особисті дані: він публічний.

## Що потрібно

- [Git](https://git-scm.com/)
- [Node.js 22 або новіша](https://nodejs.org/en/download) (npm встановлюється разом із Node.js)
- Редактор [Cursor](https://cursor.com)

Версії перевірте командами:

```bash
git --version
node -v
```

## Отримання коду

Замініть `<ваш-логін>` і `<ваше-імʼя>`:

```bash
git clone https://github.com/<ваш-логін>/SDDwithAI26-<ваше-імʼя>.git
cd SDDwithAI26-<ваше-імʼя>
```

> **Windows:** клонуйте ближче до кореня диска (наприклад, `C:\Projects`): у проєкті глибока вкладеність папок, а Windows має обмеження на довжину шляху. Якщо під час `git clone` або `npm install` з'являється помилка про довгі шляхи, виконайте один раз: `git config --global core.longpaths true`.

Без Git: на сторінці вашої копії натисніть **Code → Download ZIP** і розпакуйте архів.

## Встановлення й запуск

Скопіюйте файл змінних середовища (єдина змінна необов'язкова, значення за замовчуванням достатньо):

```bash
cp .env.example .env
```

(Windows PowerShell: `Copy-Item .env.example .env`.)

Встановіть залежності (це може тривати кілька хвилин) і запустіть застосунок:

```bash
npm install
npm run dev
```

Коли термінал напише, що застосунок готовий, відкрийте http://localhost:3000/en у браузері.

Зупинити застосунок: `Ctrl + C` в терміналі. Запустити знову: `npm run dev`.

## Тести

```bash
npm test
```

Усі тести мають проходити. Налаштування Jest зупиняється на першому невдалому наборі тестів (`bail: 1`), тому якщо тест падає, ви побачите лише перший провал.

## Корисні папки

| Шлях | Що там |
|---|---|
| `app/[lang]/` | Сторінки сайту (мови `uk` і `en`) |
| `app/api/` | API-маршрути (наприклад, форма контактів) |
| `app/services/` | Бізнес-логіка |
| `app/infrastructure/` | Моделі та репозиторії бази даних |
| `scripts/seed-memory-mongo.js` | Демо-дані (seed), що завантажуються при кожному запуску |
| `i18n/messages/` | Тексти інтерфейсу (переклади) |
| `docs/` | Домовленості команди (комміти, гілки, PR, іменування) |
| `.cursor/` | Агенти й skills для Cursor (за потреби на курсі) |

## Набір для Cursor

У папці `.cursor/` лежать необов'язкові агенти (`.cursor/agents/`) та skills (`.cursor/skills/`) для вправ курсу. Усі вправи виконуються й без них звичайними промптами. Перед використанням чужих skills завжди прочитайте їхній вміст.

## Часті проблеми

| Симптом | Що робити |
|---|---|
| `npm install` падає | Перевірте `node -v` (потрібно 22 або новіша), повторіть без VPN |
| `http://localhost:3000` не відкривається | Подивіться в терміналі, на якому порту запустився застосунок (3000 може бути зайнятий) |
| Сторінка порожня після змін | Зупиніть застосунок (`Ctrl + C`) і запустіть знову: `npm run dev` |
| Не видно демо-зображень | Якщо зображення бракує, застосунок показує прозорий запасний варіант; демо-зображення лежать у `public/images/demo` |
