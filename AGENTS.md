# AGENTS.md

Це навчальна копія сайту Фундації Лятошинського для курсу Spec Driven Development with AI. Бізнес-аналітик тут перевіряє тексти, маршрути й поведінку сторінок, а не розгортає бойовий сайт: застосунок працює локально на демо-даних.

## Основні сторінки

Мова в адресі: `uk` або `en`. Приклад: `/uk/about-us`.

| Сторінка | Призначення |
|---|---|
| `/[lang]` | Головна: вхід на сайт, коротко про композитора, події, новини й співпраця |
| `/[lang]/about-us` | Про Фундацію: місія, назва й переконання організації |
| `/[lang]/biography` | Життєпис Бориса Лятошинського |
| `/[lang]/artistry` | Творчість композитора |
| `/[lang]/research` | Дослідження та наукові роботи |
| `/[lang]/archive` | Каталог архіву: пошук фондів |
| `/[lang]/archive/[fund]` | Один архівний фонд |
| `/[lang]/archive/[fund]/[case]` | Справа фонду: шифр, дати, документи |
| `/[lang]/news` | Новини Фундації |
| `/[lang]/cooperation` | Співпраця для партнерів, благодійників і меценатів |
| `/[lang]/support-us` | Підтримка Фундації внеском |
| `/[lang]/war-in-ukraine` | Робота Фундації під час війни в Україні |
| `/[lang]/contacts` | Звернення: запит, на який відповідають протягом кількох робочих днів |
| `/[lang]/privacy-policy` | Політика конфіденційності |
| `/[lang]/terms` | Умови користування сайтом |

## Конвенції

- Код пишемо на TypeScript.
- Експортуйте іменовані функції та компоненти. `export default` лишайте лише у файлах маршрутів Next.js (`page.tsx`, `layout.tsx`, `route.ts`): фреймворк вимагає його там.
- Основна мова інтерфейсу — українська (`uk`). Англійська (`en`) — друга мова. Тексти лежать у `i18n/messages/`.

## Навчальний репозиторій

Це шаблон для навчання, не бойовий сайт. При кожному `npm run dev` база MongoDB створюється в пам’яті й наповнюється демо-даними зі `scripts/seed-memory-mongo.js`. Після зупинки процесу дані зникають.
